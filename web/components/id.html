🆔 id — Identifiers, Tokens, UUIDs

Generate UUID v4/v7 and secure random tokens. Mirrors sarra id uuid and sarra id random. Full docs →

uuid — Generate UUIDs

v4 random (default) · v7 time-ordered, recommended for DB keys.

Output appears here…
sarra id uuid --uuid-version v7 --count 5

random — Secure random tokens

Hex tokens, length = bytes (16 bytes → 32 hex chars).

Output appears here…
sarra id random --length 32 --count 5
