🔐 crypto — Hashing, Encoding, Encryption

Browser WebCrypto parity with CLI. AES-256-GCM and RSA-OAEP(SHA-256) round-trip with CLI output. Keys never leave this page.

hash — md5 / sha1 / sha256 / sha512

…
sarra crypto hash sha256 "hello world"

base64 — encode / decode

…
sarra crypto base64 "hello" / sarra crypto base64 -d SGVsbG8=

aes-encrypt — AES-256-GCM

…
sarra crypto --format json aes-encrypt "msg" -o encrypted.json

aes-decrypt

…
sarra crypto aes-decrypt <hex> -k <key> -i <iv> -t <tag>

rsa-keygen — RSA-OAEP key pair

Keys appear here (PEM)…
sarra crypto rsa-keygen --size 2048 -o ./my-keys

rsa-encrypt / rsa-decrypt

…
sarra crypto rsa-encrypt "msg" -p public.pem
sarra crypto rsa-decrypt <b64> -k private.pem
