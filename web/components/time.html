⏱️ time — Date & time utilities

Mirrors sarra time now|convert|add|diff|parse. All parsing rules match the CLI (Unix s vs ms auto-detect).

now

…
sarra time now / sarra time now --unix / --ms / --format date

convert

…
sarra time convert 1737468322 --to iso

add / subtract

…
sarra time add --days 5 --hours 2
sarra time add "2026-01-21T10:00:00Z" --days -3

diff / parse

…
sarra time diff "2026-01-21T00:00:00Z" "2026-02-01T00:00:00Z" --unit days
sarra time parse "2026-01-21" --verbose
