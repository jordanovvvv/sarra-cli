📍 geo — IP & network

Validate works offline. My-IP / lookup call the same APIs as the CLI only after you opt in.

validate — IPv4 / IPv6 (offline)

…
sarra geo validate 192.168.1.1

my-ip / lookup (opt-in network)

…
sarra geo my-ip --ipv4
sarra geo lookup 8.8.8.8

local — interfaces (CLI-only, by design)

Browsers sandbox network interfaces, so this card shows what the page can see plus the exact CLI workflow.

…
sarra geo local
sarra geo --format json local
