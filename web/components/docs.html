📚 docs — Detailed reference + MkDocs

Each card above shows its CLI equivalent. This viewer renders the package's docs/*.md files (same source as --help) with MkDocs-style navigation.

Serve the repo root for fetch to work, e.g. npx serve . then open /web/index.html.
Choose a document to render it here.

Run the full MkDocs site (recommended for publishing)

pip install mkdocs-material
mkdocs serve   # serves docs/ + README at localhost:8000

Minimal mkdocs.yml is included at the repo root and points at the existing docs/*.md files — no duplication:

site_name: Sarra CLI
theme: { name: material }
nav:
  - Home: README.md
  - id: docs/id-help.md
  - crypto: docs/crypto-help.md
  - data: docs/data-help.md
  - qr: docs/qrcode-help.md
  - time: docs/time-help.md
  - ssl: docs/ssl-help.md
  - geo: docs/geo-help.md

Doc → CLI → Web map

  • docs/id-help.md → sarra id → ID section (UUID versions, counts, JSON parity).
  • docs/crypto-help.md → sarra crypto → hash/base64/AES/RSA cards.
  • docs/data-help.md → sarra data json → format/query/merge/CSV.
  • docs/qrcode-help.md → sarra qr → EC levels L/M/Q/H, sizes, colors.
  • docs/time-help.md → sarra time → ISO/unix/ms/date/time/locale.
  • docs/ssl-help.md → sarra ssl → self-signed vs Let's Encrypt trust guide.
  • docs/geo-help.md → sarra geo → offline validate vs online lookup limits.
