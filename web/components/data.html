🧩 data — JSON format, validate, query, merge, CSV

Mirrors sarra data json <format|minify|validate|query|merge|to-csv>. Paste JSON or upload a file.

format / minify / validate

…
echo '{"a":1}' | sarra data json format
sarra data json validate config.json

query — dot path

Uses the pasted JSON on the left. Syntax: user.name, items[0].id.

…
sarra data json query "user.name" data.json

merge — combine objects

…
sarra data json merge base.json override.json -o merged.json

to-csv — array of objects → CSV

…
sarra data json to-csv users.json -o users.csv
